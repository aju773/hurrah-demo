# Fonts

Used only by `orders/artwork_templates.py`, to draw the labels on Artwork templates so they do not depend on
fonts installed on the host. Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

- `LiberationSans-Regular.ttf` — Liberation Sans, Latin text (Size names, measurements).
- `NotoSansArabic-Regular.ttf` — Noto Sans Arabic, copyright The Noto Project Authors, Arabic text and digits.
  It has no Latin letters, so Arabic lines use only Arabic words, digits and Arabic punctuation.
